# Plasma frontiers and kinetic-plasma algorithms (2022–2026), as calculators for `plasmoid` and its neighbours

Every number marked "recomputed" is reproduced by `plasma_frontiers_checks.py` (this directory, standard library only, `python3 -I plasma_frontiers_checks.py`; all checks pass). Downloaded PDFs were isolated in their own directories in the session scratchpad and read only as text with `pdftotext`. The NRL Plasma Formulary itself could not be fetched (NRL returns HTTP 403, the MIT PSFC mirror fails certificate verification), so NRL formulas below are recalled and then checked by derivation or against PlasmaPy; they are marked as such.

What the crates already have (read from the READMEs and sources, 2026-10-25):

- `plasmoid::fusion`: Bosch–Hale, `lawson` (Wurzel & Hsu), screening/`salpeter`, `C_BREMS = 5.34e-37`. `plasmoid::pinch`: `Resistivity::{Perpendicular, Parallel}` (NRL `η⊥ = 1.03e-4 Z lnΛ T^-3/2`, `η∥ = η⊥/1.96`) used only inside `pease_braginskii`; `plasmoid::relaxation::lundquist` hard-codes the same coefficient. No Debye length, plasma parameter, Coulomb-logarithm function, collision frequency, `Z(ζ)`, Landau damping, ICF hot-spot metrics, Γ, Thomas–Fermi or IPD anywhere in the workspace (grep of `crates/*/src`).
- `magnetics::mhd`: Alfvén/magnetosonic speeds, beta, magnetic diffusivity and Reynolds number (taking a conductivity), Hartmann, Prandtl, Elsasser, inertial length, gyroradius. `gravitational::hf::plasma_frequency` and `critical_density` exist (in the gravitational-wave crate, not `plasmoid`).
- Examples: `plasmoid/examples/fusion_yields.rs` already has NIF N250406 (8.6 MJ from 2.08 MJ) and JET's 69.26 MJ; `triple_products.rs` has W7-X 2017 (3.5 keV, 8×10¹⁹ m⁻³, 0.22 s, 6.2×10¹⁹ keV s m⁻³).
- The earlier research (`research/topics/plasmoids-and-fusion/report.md`) planned a public `spitzer_eta(t_e_ev, z, ln_lambda, kind)` that was never built.

## Kinetic-plasma mathematics: Z(ζ), w(z), Landau damping, Bohm–Gross, Debye length and plasma parameter

### Takeaway
The Faddeeva function can be built in a few dozen lines and verified against Zaghloul & Ali's Mathematica reference table to 1×10⁻¹³, and the exact Langmuir root it gives at kλ_D = 0.5 (ω = 1.415662 − 0.153359i ω_pe) matches the Vlasov-code benchmark to six digits; the one trap is that rational-series algorithms (Weideman) lose all relative accuracy in Re w near the real axis, which corrupts weak Landau damping below ~10⁻¹³ ω_pe unless the real-axis term `√π e^(−ξ²)` is handled explicitly.

### Cited Findings
- **Definitions.** `Z(ζ) = π^(−1/2) ∫ e^(−x²)/(x − ζ) dx` (Fried & Conte 1961), with `Z(ζ) = i√π w(ζ)` and `w(z) = e^(−z²) erfc(−iz)`; PlasmaPy's docstring test values: `Z(0) = 1.77245385…i`, `Z(1+i) = −0.36905845… + 0.54014504…i`, `Z(0.3) = −0.56526333 + 1.61990085i`, `Z(0.7+2.3i) = −0.09995023 + 0.37685142i` — [PlasmaPy plasma_dispersion_func](https://docs.plasmapy.org/en/stable/api/plasmapy.dispersion.dispersion_functions.plasma_dispersion_func.html). Recomputed: all to 1×10⁻⁸ (the docstring truncates digits); `Z′ = −2[1 + ζZ]` verified by finite difference to 2×10⁻¹⁰.
- **Zaghloul & Ali (2011), Algorithm 916, ACM TOMS 38(2) 15, DOI 10.1145/2049673.2049679.** Real and imaginary parts of erf(z) from Salzer's representation of `e^(t²)` with free parameter `a` (relative error `E ≈ 2e^(−π²/a²)`: a = 0.5 gives 1.43×10⁻¹⁷); Eqs. (9)–(10):
  `Re erf(z) = erf(x) + (a/(πx))e^(−x²)(1 − cos 2xy) + (8a/π)e^(−x²) Σₙ e^(−a²n²)/(4a²n² + 4x²)·[x − x cosh(2any)cos(2xy) + an sinh(2any) sin(2xy)]`,
  `Im erf(z) = (4a/π)e^(−x²)(4x)⁻¹ sin(2xy) + (8a/π)e^(−x²) Σₙ e^(−a²n²)/(4a²n² + 4x²)·[x cosh(2any) sin(2xy) + an sinh(2any) cos(2xy)]`,
  and limits `V(0, y) = erfcx(y)`, `V(x, y→0) = e^(−x²)`, `L(x, y→0) = (2/√π)F(x)` (F = Dawson) — [arXiv 1106.0151](https://arxiv.org/abs/1106.0151).
- **Zaghloul & Ali Table 2 (Mathematica erfi-based reference values)**, test vectors (x, y → Re w, Im w): (0.063, 10⁻²⁰) → 0.9960388660702479, 0.07090008726353683; (6.3, 10⁻²⁰) → 5.792460778844102×10⁻¹⁸, 0.09072765968412736; (6.3, 10) → 0.04040671157393860, 0.02527577277549421; (1, 10⁻²⁰) → 0.3678794411714423, 0.6071577058413937; (5.5, 10⁻¹⁴) → 7.307386729528773×10⁻¹⁴, 0.1043674364367812; (630, 10) → 1.421137820009847×10⁻⁵, 8.953145713915760×10⁻⁴; (0.063, 200) → 2.820912377324508×10⁻³, 8.885651855627418×10⁻⁷ — [arXiv 1106.0151](https://arxiv.org/abs/1106.0151). Recomputed: nine points by a 90-digit Taylor series `w = Σ (iz)ⁿ/Γ(n/2+1)` and three far-field points by Laplace's continued fraction, all to 1×10⁻¹³ relative.
- **Poppe & Wijers (1990), Algorithm 680, ACM TOMS 16, 38, DOI 10.1145/77626.77629**: claims 14 significant digits but loses Re w catastrophically near x = 6.3 for small y (relative error up to 100%: it returns 1.479×10⁻²² against the true 5.792×10⁻¹⁸ at (6.3, 10⁻²⁰)) — [Zaghloul & Ali 2011, Tables 2–3](https://arxiv.org/abs/1106.0151).
- **Weideman (1994), SIAM J. Numer. Anal. 31, 1497, DOI 10.1137/0731077**: Zaghloul & Ali report that it returns negative Re w near the real axis for every N (16–256) at y = 10⁻²⁰ and overestimates V by up to six orders of magnitude there — [arXiv 1106.0151](https://arxiv.org/abs/1106.0151). The algorithm (written from the paper's published MATLAB listing, recalled, not fetched this session): `M = 2N`, `L = √(N/√2)`, `θ_k = kπ/M`, `t_k = L tan(θ_k/2)`, `f_k = e^(−t_k²)(L² + t_k²)` for k = −M+1…M−1, `a_n = (1/2M) Σ_k f_k cos(nθ_k)`, `Z = (L + iz)/(L − iz)`, `w(z) = 2Σ_{n=1}^{N} a_n Z^(n−1)/(L − iz)² + 1/(√π(L − iz))` for Im z ≥ 0; below the axis `w(z) = 2e^(−z²) − w(−z)`. Recomputed with N = 32: absolute error ≤ 3.2×10⁻¹⁴ at all nine Table 2 points, but Re w(6.3 + 10⁻²⁰i) = −1.3×10⁻¹⁴ (relative error 2×10³), confirming the published failure.
- **Langmuir-wave Landau damping benchmark** (Maxwellian, kλ_D = 0.5): analytic γ = 0.1533 ω_pe and ω = 1.416 ω_pe — [arXiv 2109.06743](https://arxiv.org/abs/2109.06743); electric-field decay rate 0.153359 (half the energy rate 0.306718) — [arXiv 2301.05581](https://arxiv.org/abs/2301.05581). Recomputed by Newton iteration on `1 + (kλ_D)⁻²[1 + ξZ(ξ)] = 0`, `ξ = ω/(√2 k v_t)`, `v_t = √(T/m)`: **ω = 1.415662 − 0.153359i ω_pe**.

### Inferences
- **Catalogue item K1 — `plasmoid::kinetic::faddeeva(z) -> Complex` and `plasma_dispersion(zeta)`, `plasma_dispersion_deriv(zeta)`.** Formula and tests as above. Implementation advice: Weideman N = 32 for the bulk plane (cheap, 3×10⁻¹⁴ absolute), Laplace continued fraction for |z| > ~15, and a real-axis branch (`Re w = e^(−x²)`, `Im w = 2F(x)/√π`, first-order Taylor in y via `w′ = −2zw + 2i/√π`) for |y| ≲ 10⁻³ — or port Zaghloul–Ali's Eqs. (9)–(10) outright, which has none of these failure modes. Rust has no complex type in std, so a two-field struct is needed (no dependency). Tests: the nine Zaghloul–Ali points to 10⁻¹³ relative in both parts, PlasmaPy's four Z values to 10⁻⁸, `w(2i) = e⁴ erfc(2) = 0.2553956763`, Dawson F(1) = 0.5380795069127684. Status: established (algorithms 1990–2011, foundational, older than the 2022 window but needed by every kinetic item). Cross-crate: also gives the Voigt line shape `Re w((x + iγ)/(σ√2))/(σ√(2π))`, usable by spectroscopic metrology; optional.
- **K2 — `kinetic::langmuir(k_lambda_d) -> Complex` (exact root) with `bohm_gross(k_lambda_d) = √(1 + 3k²λ_D²)` and `landau_weak(k_lambda_d) = √(π/8)(kλ_D)⁻³ exp(−1/(2k²λ_D²) − 3/2)`.** Recomputed table (ω/ω_pe): kλ_D = 0.2: 1.063984 − 5.511×10⁻⁵i (Bohm–Gross 1.058301, weak formula 6.51×10⁻⁵); 0.3: 1.159846 − 0.012620i (1.126943; 0.0200); 0.4: 1.285057 − 0.066128i (1.216553; 0.0960); 0.5: 1.415662 − 0.153359i (1.322876; 0.1514). At kλ_D = 0.1 the Newton root's imaginary part (8×10⁻¹⁵) is Weideman noise; the perturbative rate with exact `Im Z = √π e^(−ξ²)` gives 2.61×10⁻²⁰, within 3% of the weak formula's 2.70×10⁻²⁰. Test: kλ_D = 0.5 to 10⁻⁴ against the benchmark. Status: established.
- **K3 — `kinetic::ion_acoustic(k_lambda_de, te_over_ti, mass_ratio)`**, root of `1 + (kλ_De)⁻²[1 + ξ_eZ(ξ_e)] + (T_e/T_i)(kλ_De)⁻²[1 + ξ_iZ(ξ_i)] = 0`, with Ω = ω/ω_pi, `ξ_e = Ω/(√2 kλ_De √μ)`, `ξ_i = Ω√(T_e/T_i)/(√2 kλ_De)`. Recomputed for hydrogen at kλ_De = 0.1: T_e/T_i = 3 → Ω = 0.151926, −γ/ω = 0.1697; 5 → 0.134703, 0.0894; 10 → 0.117661, 0.0276; 20 → 0.107734, 0.0133. The common small-k estimate `√(π/8)[√(m_e/m_i) + τ^(3/2)e^(−τ/2−3/2)]` is off by up to 60% at τ = 5–10, so the exact root earns its place. No published table was retrieved, so the test must be internal (the fluid limit `kc_s`, `c_s² = (T_e + 3T_i)/m_i`, as T_e/T_i → ∞, and continuity in τ). Status: established physics; self-computed test values.
- **K4 — `plasmoid::collisions::debye_length(n, t_ev) = √(ε₀T/(ne²))` and `plasma_parameter = (4π/3)nλ_D³`.** At PlasmaPy's reference point (n_e = 10¹⁹ m⁻³, T = 10⁶ K = 86.17 eV) recomputed λ_D = 2.18226×10⁻⁵ m, N_D = 4.353×10⁵, ln(12πnλ_D³) = 15.18. The identity `λ_D = √(T/m_e)/ω_pe` (checked to 10⁻¹⁴) joins this to `gravitational::hf::plasma_frequency`, which should move to (or be re-exported from) `plasmoid` so both crates share one definition. Cross-crate: plasmoid + gravitational. Status: established.
- **K5 — the kinetic Jeans twin (`physica::analogies`, calling `plasmoid::kinetic`).** A collisionless self-gravitating Maxwellian obeys `1 − (k_J/k)²[1 + ξZ(ξ)] = 0`, the Langmuir relation with the sign of the restoring term flipped (ω_p² → −4πGρ), so the same `plasma_dispersion` serves both. On the unstable branch ω = iγ this reduces to `(k/k_J)² = 1 − √π y erfcx(y)`, `γ = √2 (k/k_J) y ω_J`. Recomputed: γ = 0.687202 ω_J at k = k_J/2, 0.155829 at 0.9k_J, 0.015921 at 0.99k_J, → ω_J as k → 0 (the cold Jeans rate) and → 0 at k = k_J (Jeans's marginal wavenumber). These are derived here, not taken from a fetched source; the derivation follows the standard stellar-dynamics form (Lynden-Bell 1962; Binney & Tremaine), which should be fetched before shipping. Cross-crate: plasmoid + physica + metrology (G); it sits naturally beside the existing Bennett–Ostriker twin. Status: established physics, test values self-computed.

- Weideman's paper was not fetched; the algorithm is written from the well-known published MATLAB listing and verified only by its agreement with the Zaghloul–Ali table (3×10⁻¹⁴).
- No published tabulation of ion-acoustic Landau rates (for example Fried & Gould 1961) was retrieved, so K3 has no external test vector.
- No published γ(kλ_D) table beyond kλ_D = 0.5 was fetched; the commonly quoted 0.4 values were not verified.
- A source for the kinetic Jeans dispersion relation was not fetched.

## Collisions and transport: Coulomb logarithms, collision frequencies, Spitzer and Braginskii, Bohm and gyro-Bohm

### Takeaway
The crates carry the NRL Spitzer coefficient in two private places but no Coulomb logarithm, collision time or Z-dependent Spitzer factor; three common lnΛ conventions differ by 1.7 at one ordinary laboratory point, and the 2021 Sadler–Walsh–Li / Davies–Wen–Ji–Held re-fits (two independent teams, mutually consistent) supply the Epperlein–Haines α∥(Z) and β∥(Z) table that turns the hard-coded `η⊥/1.96` into a tested function of Z.

### Cited Findings
- **PlasmaPy `Coulomb_logarithm`**: straight-line methods `lnΛ = ln(b_max/b_min)`, hyperbolic `½ln(1 + b_max²/b_min²)`; `classical`: `b_min = max(λ_dB, ρ⊥)`, `b_max = λ_D`; GMS-1…GMS-6 interpolate `√(λ_dB² + ρ⊥²)` and `√(λ_D² + a_i²)`; GMS-6 recommended for strongly coupled plasmas. Example: n_e = 10¹⁹ m⁻³, T = 10⁶ K, e–p: 14.545527556…, and 11.363478378… with V = 10⁶ m/s — [PlasmaPy Coulomb_logarithm](https://docs.plasmapy.org/en/stable/api/plasmapy.formulary.collisions.coulomb.Coulomb_logarithm.html). Recomputed both to 10⁻⁸ with `ρ⊥ = e²/(4πε₀μV²)`, `λ_dB = ħ/(2μV)`, `V = √(2kT/μ)`, `λ_D` electron-only.
- **PlasmaPy `Spitzer_resistivity`** is `η = m ν₁₂/(n Z₁Z₂e²)` with PlasmaPy's own collision frequency; example 2.4915…×10⁻⁶ Ω m at the same point — [PlasmaPy Spitzer_resistivity](https://docs.plasmapy.org/en/stable/api/plasmapy.formulary.collisions.misc.Spitzer_resistivity.html). Recomputed as `μ·nπ(2ρ⊥)²V lnΛ/(ne²)` = 2.4923×10⁻⁶ (3×10⁻⁴ residual untraced). This is 1.43× NRL's η⊥ and 2.8× NRL's η∥ at that point, so PlasmaPy's "Spitzer" is a cross-section estimate, not the Spitzer–Härm value; do not use it as a test of the crate's resistivity.
- **Sadler, Walsh & Li (2021), PRL 126, 075001, DOI 10.1103/PhysRevLett.126.075001**, Table I (unmagnetised α∥ and β∥ with the fit parameters, from their Fokker–Planck solutions following Epperlein & Haines' method): α∥ for Z̄ = 1, 2, 3, 4, 5, 6, 7, 8, 10, 12, 14, 20, 30, 60 = 0.5061, 0.4295, 0.3950, 0.3750, 0.3618, 0.3524, 0.3454, 0.3399, 0.3319, 0.3263, 0.3221, 0.3144, 0.3081, 0.3015; β∥ = 0.7029, 0.9054, 1.0180, 1.0923, 1.1456, 1.1861, 1.2180, 1.2439, 1.2834, 1.3121, 1.3341, 1.3770, 1.4139, 1.4547. New fits for the cross-Hall and cross-gradient-Nernst coefficients: `δ∧(χ, Z̄) = [χ + (1 − α∥)χ²]/(a₀ + a₁χ + a₂χ² + χ³)`, `γ∧(χ, Z̄) = (χ + β∥χ²)/(b₀ + b₁χ + b₂χ² + χ³)`, Z̄ = 1 row a = (3.8566, 4.8675, 9.7813), b = (0.5589, 1.0599, 2.1643); maximum error 10% (δ∧) and 8% (γ∧) against the kinetic results; the Epperlein–Haines (1986) and Ji–Held fits give wrong χ → 0 limits — [arXiv 2009.04562](https://arxiv.org/abs/2009.04562).
- **Replication**: errors in Epperlein & Haines at low magnetisation were found and corrected simultaneously by Sadler, Walsh & Li (PRL 2021) and Davies, Wen, Ji & Held (Phys. Plasmas 2021), and the two sets agree — [Walsh, Sadler & Davies, arXiv 2107.12988](https://arxiv.org/abs/2107.12988).
- **Recalled NRL formulas** (NRL Plasma Formulary 2019/2023; source page returned 403 — [NRL formulary page](https://www.nrl.navy.mil/ppd/content/nrl-plasma-formulary)); n in cm⁻³, T in eV:
  - `lnΛ_ee = 23.5 − ln(n_e^½ T_e^(−5/4)) − [10⁻⁵ + (ln T_e − 2)²/16]^½`;
  - `lnΛ_ei = 23 − ln(n_e^½ Z T_e^(−3/2))` for T_i m_e/m_i < T_e < 10Z² eV; `24 − ln(n_e^½ T_e⁻¹)` for T_e > 10Z² eV; `16 − ln(n_i^½ T_i^(−3/2) Z² μ)` for T_e < T_i Z m_e/m_i;
  - `lnΛ_ii′ = 23 − ln{ZZ′(μ + μ′)/(μT_i′ + μ′T_i)·(n_iZ²/T_i + n_i′Z′²/T_i′)^½}`;
  - `τ_e = 3.44×10⁵ T_e^(3/2)/(n lnΛ)` s; `η⊥ = 1.03×10⁻² Z lnΛ T^(−3/2)` Ω cm; Bohm `D_B = kT/(16eB) = 6.25×10⁶ T B⁻¹` cm² s⁻¹ (B in gauss).

### Inferences
- **Catalogue item C1 — `plasmoid::collisions::coulomb_log(kind, …)` with `Nrl::{ElectronElectron, ElectronIon, IonIon}` and `Classical { v }`.** Recomputed at n_e = 10¹⁹ m⁻³, 86.17 eV: classical (PlasmaPy) 14.5455, NRL e–i 13.4896, ln(12πnλ_D³) 15.1811. The spread (1.69, 12%) is the convention, not an error; the function must name its convention, and `pinch::pease_braginskii` and `relaxation::lundquist` (which take `ln_lambda` as an argument) gain a tested way to fill it. Tests: PlasmaPy's 14.545527556 and 11.363478378 to 10⁻⁸. Status: established.
- **C2 — `collisions::tau_e(n, t_ev, ln_lambda, z)` (Braginskii).** Derived `τ_e = 6√2 π^(3/2) ε₀² √m_e T^(3/2)/(lnΛ e⁴ Z n_i)` gives the NRL coefficient 3.4408×10⁵ (n in cm⁻³), and `η⊥ = m_e/(ne²τ_e)` gives 1.0314×10⁻⁴ Ω m — exactly the constant the crate already hard-codes. Status: established.
- **C3 — `collisions::spitzer_eta(t_ev, z, ln_lambda, Direction)` with `η∥ = α∥(Z) η⊥`, α∥ from Sadler et al.'s Table I (interpolated in Z).** Tests: `(3π/32)/α∥(Z)` reproduces Spitzer & Härm's γ_E: 0.5819 (Z = 1; SH 0.582), 0.6857 (Z = 2; 0.683), 0.7854 (Z = 4; 0.785) — the γ_E values are recalled from Spitzer & Härm 1953 (Phys. Rev. 89, 977), not fetched; α∥(60) = 0.3015 approaches the Lorentz limit 3π/32 = 0.2945 and β∥(60) = 1.4547 approaches 3/2. Note: `1/α∥(1) = 1.976`, 0.8% above NRL's 1.96 used in `pinch::Resistivity::Parallel` — keep 1.96 for the published Pease–Braginskii and Lundquist tests, and expose the Z table for everything else. Cross-crate: the conductivity `1/η` feeds `magnetics::mhd::magnetic_diffusivity`, `magnetic_reynolds` and `free_decay_time`, and `relaxation::lundquist` should call it instead of its private constant (plasmoid + magnetics). Status: Spitzer established; the Z table recent and replicated (2021, two teams).
- **C4 — `collisions::cross_nernst(chi, z)` and `cross_hall(chi, z)`** from the Sadler fits; recomputed γ∧(χ = 1, Z = 1) = 0.35602. Tests: the χ → 0 limits δ∧ → 0 and γ∧ → 0 that the fits were built to restore, and the table row coefficients. Applications: magnetised ICF/MagLIF heat flow. Status: recent and replicated.
- **C5 — `collisions::bohm(t_ev, b) = T/(16B)` m²/s and `gyro_bohm(t_ev, b, m, a) = (ρ_s/a)·D_B`**, with ρ_s from `magnetics::mhd::gyroradius` (plasmoid + magnetics). Test: NRL's 6.25×10⁶ cm²/s at 1 eV, 1 G (recomputed exactly). Status: established as an empirical/dimensional scaling, not a derived transport law; label it so.

### Gaps
- The NRL 2023 PDF was not retrievable; the NRL Coulomb-logarithm and collision-rate coefficients are recalled. The τ_e and η coefficients were re-derived and match; the lnΛ_ee and lnΛ_ii constants were not independently verified.
- The Davies, Wen, Ji & Held (2021) paper itself and the Braginskii ion-conductivity value were not fetched; κ∥e (γ₀ = 3.1616 for Z = 1 in Epperlein–Haines) is recalled only.
- The 3×10⁻⁴ residual against PlasmaPy's Spitzer_resistivity example is untraced (mass convention or version).

## Fusion results 2022–2026 and the ICF ignition criteria applied to them

### Takeaway
NIF has now ignited 11 times (to 20 June 2026), with a record 8.6 MJ from 2.08 MJ (gain 4.13), and the 2022 PRL that declared the Lawson criterion exceeded publishes a complete table (pressure, volume, temperatures, burn width, areal density, yield) from which the hot-spot energy, the Christopherson alpha-energy criterion, target gains and even the measured 1.37 MJ yield (to 2%) can be recomputed in a few lines; magnetic-confinement records of 2023–2025 are long-pulse energy-turnover records (W7-X 1.8 GJ, WEST 2.6 GJ over 1337 s, EAST 1066 s) whose numbers are simple but whose triple products are not yet published in the press.

## Stellarator figures of merit with published W7-X and HSX values

### Takeaway
Simple, published stellarator numbers are scarcer than expected: W7-X was designed for an effective ripple of about 1%, and Landreman & Paul's 2022 precisely quasisymmetric fields publish exact rotational transforms, aspect ratios and field periods, but no fetched source gives a numeric ε_eff for W7-X's standard configuration or HSX, so ε_eff and the 1/ν transport law can be shipped only with self-consistency tests for now.

### Cited Findings
- W7-X design: an effective ripple of about 1% at all radii keeps neoclassical transport sufficiently low even at higher temperatures — [EUROfusion WPS1PR15 manuscript (search snippet)](https://scipub.euro-fusion.org/wp-content/uploads/eurofusion/WPS1PR15_14373_submitted.pdf). Andreeva, Kisslinger & Wobig (2002) tabulate ε_eff for nine W7-X configurations — [VANT 2002 (search snippet)](https://vant.kipt.kharkov.ua/ARTICLE/VANT_2002_4/article_2002_4_45.pdf).
- HSX: N = 4 field periods, m = 1 quasi-helical symmetry, effective transform ≈3; a high-ripple configuration has nearly 4× the effective ripple of the "mirror" configuration; in the real HSX field there are 30 local B minima over ~6 field periods against 5 in the ideal QHS field (Nemov, Kasilov et al. EPS 2012) — [HSX quasisymmetry tests](https://hsx.wisc.edu/wp-content/uploads/sites/747/2016/03/Experimental-Tests-of-Quasisymmetry-in-HSX.pdf); [EPS 2012 P5.073](https://lac913.epfl.ch/epsppd3/2012/pdf/P5.073.pdf) (search snippets; no absolute ε_eff).
- **Landreman & Paul (2022), PRL 128, 035001, DOI 10.1103/PhysRevLett.128.035001**: symmetry-breaking Fourier amplitudes throughout a volume of aspect ratio 6 as small as ~50 µT at a 1 T mean field (comparable to the geomagnetic field), vacuum ι > 0.4. QA: n_fp = 2, A = 6.0, ι from 0.423 on axis to 0.416 at the edge; QH: n_fp = 4, A = 8.0, ι ≈ 1.24 nearly constant. Objective `f_QS = Σ_j ⟨[(1/B³)((N − ιM)B×∇B·∇ψ − (MG + NI)B·∇B)]²⟩` on s = 0, 0.1, …, 1. Reactor-scaled (a = 1.7 m, B = 5.7 T) 5000 alpha particles from s = 0.25 followed for 0.2 s: none lost in QH, QA+well and QH+well; earlier designs lost ~1/4 — [arXiv 2108.03711](https://arxiv.org/abs/2108.03711); [ar5iv text](https://ar5iv.labs.arxiv.org/html/2108.03711).
- Effective ripple is not quoted numerically in Landreman & Paul's text: their ε_eff^(3/2) values are said to be so small that collisional transport will almost certainly be weaker than turbulent transport — [ar5iv](https://ar5iv.labs.arxiv.org/html/2108.03711).
- W7-X achieved volume-averaged β = 3% at reduced field in 2025 — [IPP](https://www.ipp.mpg.de/5532945/w7x).

### Inferences
- **Catalogue item S1 — `plasmoid::stellarator::Config { iota_axis, iota_edge, aspect, n_fp }` with Landreman–Paul's QA and QH as constants** and `safety_factor = 1/ι` (QA: q = 2.36–2.40; QH: q = 0.806), so `tokamak::q95`-style checks can compare tokamaks and stellarators. Tests: the published ι, A, n_fp themselves and the symmetry-breaking ratio 50 µT/1 T = 5×10⁻⁵. Status: recent and replicated (numerically reproduced by later optimisation work, which was not fetched here).
- **S2 — `stellarator::one_over_nu_diffusion(eps_eff, v_d, nu)`**, the Nemov (1999) 1/ν regime `D ∝ ε_eff^(3/2) v_d²/ν`: only its ε_eff^(3/2) scaling can be tested (W7-X's ~1% against a hypothetical 10% ripple gives 1/31.6 of the 1/ν transport). The prefactor (recalled as 4/(9π)(2)^(3/2), not fetched) should not ship until Nemov et al. (Phys. Plasmas 6, 4622) is read. Status: established formula, not yet verified here.
- **S3 — `stellarator::beta_volume(...)`** reusing `magnetics::mhd::beta` and `tokamak` conventions, tested against W7-X's 3% at 70% field — plasmoid + magnetics. Weak test (needs the 2025 pressure profile).
- Rotational transform of a simple analytic field (for example ℓ = 2 helical windings) could be computed from `magnetics::magnets` loop fields by field-line tracing, a genuine magnetics–plasmoid link, but no published simple-geometry ι value was retrieved to test it.

### Gaps
- No numeric ε_eff for W7-X's standard configuration, HSX's QHS configuration or the Landreman–Paul fields was retrieved (the values exist in Andreeva et al. 2002, Nemov et al. 2012 and Landreman & Paul's figures).

## Warm dense matter and dense plasmas: Γ, Thomas–Fermi ionization, ionization potential depression

### Takeaway
The coupling parameter and More's Thomas–Fermi fit are short, established formulas (the fit's coefficients are confirmed in a public LANL code), and the IPD question remains contested: a 2024 LCLS magnesium measurement puts the depression at 1.30 ± 0.04 of Stewart–Pyatt and 0.88 ± 0.03 of Ecker–Kröll, between the two, and the two fitted factors are mutually consistent with the models' own ratio (1.477 measured-implied against 1.488 computed), which gives a clean published test.

### Cited Findings
- **Pérez-Callejo, Gawne, Preston, …, Rose & Wark (2024), PRE 109, 045204, DOI 10.1103/PhysRevE.109.045204**: solid-density Mg heated by LCLS (1540 eV, 100 fs, 54 nm foils, ~10¹⁷ W cm⁻²); Li-like M-shell dielectronic satellites; IPD forms `ΔI_SP = C_SP(3/2)[(Z+1)e²/(4πε₀)][4πn_e/(3(Z+1))]^(1/3)` (high-density SP, ≈ ion-sphere) and `ΔI_EK = C_EK[(Z+1)e²/(4πε₀)][4π(n_e + n_i)/3]^(1/3)`, Z the ion charge; fitted C_EK = 0.88 ± 0.03 and C_SP = 1.30 ± 0.04; DFT (Gawne et al.) gives 133% of SP and 89% of EK; unscaled EK leaves almost no bound M-shell — [arXiv 2310.03590](https://arxiv.org/abs/2310.03590); [APS](https://link.aps.org/doi/10.1103/PhysRevE.109.045204).
- Earlier: Ciricosta et al. (2012) PRL 109, 065002, Al at LCLS, EK fits better; Hoarty et al. (2013) PRL 110, 265003, optical-laser Al He-β spectra cannot be reconciled with EK and SP is also inadequate — [arXiv 2310.03590](https://arxiv.org/abs/2310.03590).
- **Döppner et al. (2023), Nature 618, 270, DOI 10.1038/s41586-023-05996-8**: NIF x-ray Thomson scattering on beryllium shells compressed up to 30× at > 3 Gbar; reduced elastic scattering signals pressure ionization of K-shell electrons; the inferred charge state exceeds standard models and agrees with DFT — [APS DPP 2023 abstract](https://meetings-archive.aps.org/dpp/2023/go04/4/); [HZDR](https://www.fzd.de/publications/Publ-37763). A later talk argues the excess ionization cannot be explained by a different IPD model — [Gericke slides](https://indico.ijclab.in2p3.fr/event/9640/contributions/35894/attachments/24169/35114/GERICKE.pdf).
- **More's Thomas–Fermi fit** (More 1985, Adv. At. Mol. Phys. 21, 305; coefficients confirmed in LANL's Multi-BGK `zBar.c`): with R = ρ/(ZA) (ρ in g/cm³, A in amu), T in eV: `T₀ = T/Z^(4/3)`, `T_F = T₀/(1 + T₀)`, `A = a₁T₀^a₂ + a₃T₀^a₄`, `B = −exp(b₀ + b₁T_F + b₂T_F⁷)`, `C = c₁T_F + c₂`, `Q₁ = A R^B`, `Q = (R^C + Q₁^C)^(1/C)`, `x = αQ^β`, `Z̄ = Zx/(1 + x + √(1 + 2x))`; α = 14.3139, β = 0.6624, a₁ = 0.003323, a₂ = 0.9718, a₃ = 9.26148×10⁻⁵, a₄ = 3.10165, b₀ = −1.7630, b₁ = 1.43175, b₂ = 0.31546, c₁ = −0.366667, c₂ = 0.983333 — [LANL Multi-BGK zBar.c](https://github.com/lanl/Multi-BGK/blob/HEAD/src/zBar.c). Stanton, Glosli & Murillo (2018) PRX 8, 021044 use a TF average-atom Z̄ fit (their ref. 63) generalised to mixtures by pressure equilibrium `Z_α = v_α n_e`, `Σ n_αv_α = 1` — [PRX](https://doi.org/10.1103/PhysRevX.8.021044); the MSU TEMPEST tool implements it and notes TF gives Z̄ ≈ 0.99 for hydrogen at 10 keV and 0.81–4.65 for a Z = 1–10 ladder at 0.1 eV — [TEMPEST mixture ionization](https://tempest-stc.msu.edu/sites/default/files/tools/mixture-ionization.html).

### Inferences
- **Catalogue item D1 — `plasmoid::dense::coupling(z, n_i, t) = Z²e²/(4πε₀ a kT)`, `a = (3/(4πn_i))^(1/3)`, plus `degeneracy(n_e, t) = T/T_F`.** Recomputed for N210808's hot spot (n_i = 1.99×10³¹ m⁻³, 8.94 keV): Γ = 7.0×10⁻³ and λ_D = 0.16 nm, a weakly coupled, classical hot spot, which justifies the PRL's Spitzer conduction and the crate's Bosch–Hale use; the same function feeds `fusion::salpeter` screening (internal link). No external Γ test vector was retrieved; test by definition and against `magnetics`-independent limits. Status: established.
- **D2 — `dense::zbar_more(z, a, rho_gcc, t_ev)`.** Recomputed for solid aluminium (2.70 g/cc): Z̄ = 2.443 (0 eV), 2.488 (1 eV), 2.992 (10 eV), 7.109 (100 eV), 12.325 (1 keV), 12.943 (10 keV), → 13 as T → ∞. Tests available now: the T = 0 limit `x = αR^β` (closed form), monotonic rise in T, and the high-T limit; a published single-species Al value is still needed. Feeds `coulomb_log` (n_e = Z̄n_i) and the IPD functions. Status: established (fit to TF; TF itself lacks shell structure).
- **D3 — `dense::ipd_stewart_pyatt_dense(z, n_e)` and `dense::ipd_ecker_kroll(z, n_e, n_i)` with optional `c_sp`, `c_ek`.** Recomputed for Li-like Mg (Z = 9) in solid Mg (1.738 g/cc, n_i = 4.31×10²⁸ m⁻³) at Z̄ = 9: SP 117.8 eV, EK 175.3 eV, ratio 1.488 (1.494 at Z̄ = 8, 1.483 at Z̄ = 10). **Test: the model ratio EK/SP = 1.488 against the measured-implied C_SP/C_EK = 1.30/0.88 = 1.477 ± 0.07** (within 1%), and the scaled IPD 1.30 × 117.8 ≈ 0.88 × 175.3 ≈ 153–154 eV. The ratio formula `(2/3)[(Z+1)(n_e + n_i)/n_e]^(1/3)` is independent of e²/(4πε₀) and of Z̄ only weakly, so it is a robust test. Status: contested (Ciricosta 2012 favours EK; Hoarty 2013 neither; Pérez-Callejo 2024 in between; Döppner 2023 finds ionization beyond both).
- None of the dense-plasma items links naturally to the gravity crates; their cross-crate value is through `coulomb_log` and `spitzer_eta` (plasmoid ↔ magnetics via conductivity).
