# Quantum (cold-atom) satellite gravimetry: sensor physics, models, missions and studies (status October 2026)

Notation used throughout (unless a source says otherwise): k_eff = effective Raman wave number (for 87Rb at 780 nm, single-diffraction two-photon k_eff = 4*pi/lambda ~ 1.61e7 m^-1); T = time between pulses (total interferometer duration 2T); T_c (or t_c, T_cycle) = cycle time; N (N_det) = detected atoms per shot; C = fringe contrast; 1 E (Eotvos) = 1e-9 s^-2, 1 mE = 1e-12 s^-2, 1 uE = 1e-15 s^-2. "ASD" = amplitude spectral density (square root of one-sided PSD).

Source handling note: PDFs for Trimeche 2019, Carraz 2014, Zahzam 2022, Leveque 2021, Leveque 2022 (CARIOQA ICSO), Encarnacao 2024 and two NASA QGG documents were downloaded and converted with pdftotext; equations below were transcribed from those text layers. Where the PDF text layer garbled glyphs (notably Encarnacao 2024), this is flagged.

## 1. Atom-interferometry fundamentals for a simulator (phase, full phase expansions, per-shot sensitivity, shot noise, contrast, cycle time, gradiometer differencing, ASD/noise shape, microgravity advantage)

### Takeaway
A space CAI accelerometer is a Mach–Zehnder (pi/2–pi–pi/2) light-pulse interferometer whose phase is dphi = n_k * k_eff * a * T^2 (n_k = 2 for the double-diffraction scheme baselined for space), read out as P = P0 - (C/2) cos(dphi); per-shot acceleration noise is sigma_phi/(n_k k_eff T^2) with sigma_phi = 1/(C sqrt(N)) at the quantum-projection (shot-noise) limit, and the white-noise ASD is that times sqrt(T_c). A gradiometer differences two such interferometers sharing the same Raman beams (dphi_diff = n_k k_eff Gamma D T^2), giving ~3.5 mE/shot for T = 5 s, D = 0.5 m, N = 1e6; the key space advantage is long T (seconds), which needs pK-class BEC sources and active rotation compensation (tip-tilt mirror), because nadir-pointing rotation (~1.2 mrad/s) otherwise destroys contrast.

### Cited Findings

Basic measurement model and response function
- Output signal: P = P0 - (C/2) cos(dPhi), with dPhi ~ k_eff . a T^2 (P0 fringe offset, C contrast); one measured P maps to several acceleration values (fringe ambiguity a_i^n, a_i^*n), resolvable when shot-to-shot acceleration changes stay below 2*pi/(k_eff T^2); otherwise a classical sensor is needed to pick the fringe index — [Zahzam et al. 2022, arXiv:2206.00634 (PDF)](https://arxiv.org/pdf/2206.00634)
- Time-domain response: dPhi = integral k_eff . f_a(t) . a(t) dt, with triangular response f_a(t) ~ (t+T) Theta(t+T) - 2t Theta(t) + (t-T) Theta(t-T) (Theta = Heaviside, t = 0 at the central pi pulse); in frequency domain a low-pass with ~1/(2T) cut-off; the CAI is blind during dead time T_c - 2T — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- Acceleration extraction per cycle i: a_CAI,i = (e_i/(k_eff T^2)) arccos(2 (P0,i - P_i)/C_i) + n_i * 2*pi/(k_eff T^2), with e_i = +/-1 and n_i integer (both fixed by the electrostatic accelerometer in a hybrid) — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- Sensitivity function (Cheinet et al.): g(t) = 2 lim_{dphi->0} dP(dphi,t)/dphi; transfer function H(omega) = omega G(omega) where G is the Fourier transform of g; at low frequency (omega << Rabi frequency Omega_R) G(omega) ~ -(4i/omega) sin^2(omega T/2). Laser-phase-noise contribution with cycle frequency f_c: sigma_Phi^2(tau) = (1/tau) sum_{n>=1} |H(2 pi n f_c)|^2 S_phi(2 pi n f_c) (aliasing at harmonics of f_c, "similar to the Dick effect"); acceleration-noise contribution: sigma_Phi^2(tau) = (k_eff^2/tau) sum_{n>=1} |H(2 pi n f_c)|^2/(2 pi n f_c)^4 * S_a(2 pi n f_c), i.e. the acceleration transfer function falls as 1/f^4 in power; for white acceleration noise S_a (to first order in tau_R/T): sigma_Phi^2(tau) = (k_eff^2 T^4/2)(2 T_c/(3T) - 1) S_a/tau; finite Raman pulses add a first-order low-pass with cut-off f0 = (sqrt(3)/3) Omega_R/(2 pi). Full |H|^2 for finite pulses (derived from their Eq. 8): |H(omega)|^2 = 16 omega^2 Omega_R^2/(omega^2 - Omega_R^2)^2 * sin^2(omega (T+2 tau_R)/2) * [cos(omega (T+2 tau_R)/2) + (Omega_R/omega) sin(omega T/2)]^2 — [Cheinet et al., IEEE Trans. Instrum. Meas., arXiv:physics/0510197](https://ar5iv.labs.arxiv.org/html/physics/0510197)

Double diffraction (space baseline) and phase expressions
- In microgravity the atoms are at rest, so the Doppler effect cannot select one of the two Raman transitions of a retro-reflected beam; space designs therefore use double diffraction (symmetric +/- hbar k_eff), giving 2T total interaction time — [Leveque et al. 2022, CARIOQA ICSO paper, arXiv:2211.01215](https://arxiv.org/pdf/2211.01215)
- Double-diffraction phase: dPhi = 2 k_eff a T^2 (k_eff of the Raman pair) — [Leveque et al. 2021 (GRICE), arXiv:2011.03382](https://arxiv.org/pdf/2011.03382); same factor 2 in dPhi = (2 k_eff a) T^2 + Phi_L — [HosseiniArani et al. 2024, arXiv:2405.11259](https://arxiv.org/html/2405.11259v1)
- Encarnacao et al. write k_eff = 8 pi/lambda for double diffraction (i.e. the factor 2 absorbed into k_eff) and generalise with a momentum-space separation beta: dp = hbar beta k_eff, phi = (dp/hbar) a T^2 — [Encarnacao et al. 2024/2025, arXiv:2404.07835](https://arxiv.org/abs/2404.07835) (equations transcribed from PDF text layer)
- Phase with rotation (HosseiniArani Eq. 3, along-track axis x, radial initial velocity v_z0, mirror rotation Omega_M, inertial rate Omega_I, cloud offset x_0, mirror position x_M): dPhi = 2 k_eff T^2 [a_x + 2 v_z0 (Omega_y + Omega_M) - x_0 Omega_y^2 + (x_0 - x_M)(Omega_M^2 + (Omega_M - Omega_I)^2)]; with active counter-rotating mirror (Eq. 4): dPhi = 2 k_eff T^2 [a_x + x_0 Omega_y^2]; the residual x_0 Omega_y^2 is removed only if the whole sensor counter-rotates — [HosseiniArani et al. 2024](https://arxiv.org/html/2405.11259v1)
- HosseiniArani Table 2 phase budget (rad, for their GRACE-like case): non-gravitational acceleration 19.97; uncompensated rotation 8.6e-3 (fractional 4.3e-4); self-gravity 4.8e-5 (2.4e-6); gravity gradient V_xx 3.1e-6 at 2T = 10 s (3.87e-7 at 2T = 5 s) — [HosseiniArani et al. 2024](https://arxiv.org/html/2405.11259v1)
- Single-interferometer phase in a satellite frame (Trimeche Table I, double diffraction, k = 4 pi/780 nm = 16.1e6 m^-1, T_zz gradient, Omega_y pitch rate, Omega_m mirror rate, Omega_orb orbital rate), leading terms, general case: z-term 2 k z (T_zz - Omega_m^2 + Omega_y^2) T^2; v_x-term (Sagnac) 4 k v_x (Omega_y - Omega_m) T^2; v_z-term 2 k v_z (T_zz - Omega_m^2 + 4 Omega_m Omega_y - 3 Omega_y^2) T^3; output wave-packet separation dx = 4 hbar k T^2 (Omega_m - Omega_y)/m_Rb and dz = 2 hbar k T^3 (T_zz - (Omega_m - 3 Omega_y)(Omega_m - Omega_y))/m_Rb. With rotation compensated (Omega_m = Omega_y): z-term 2 k z T_zz T^2, v_z-term 2 k v_z T_zz T^3. With rotation AND gradient compensated (Omega_m = Omega_y = Omega_orb, wavevector change at the pi pulse dk = k T_zz T^2/2): all leading terms and the separation vanish — [Trimeche et al. 2019, arXiv:1903.09828](https://arxiv.org/pdf/1903.09828)
- Typical values: Omega_orb = 1.2 mrad/s (~250 km), T = 5 s, T_zz = -2.7e-6 s^-2, k = 16.1e6 m^-1; gravity-gradient differential phase 2 k D T_zz T^2 = 1087 rad for D = 0.5 m — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828)
- Gradient-compensation (dk) technique requires frequency-shift control at 1e-6 relative accuracy to meet 5 mE/shot; the shift must track the varying gradient along the orbit and the gradient can be read from the needed shift — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828)
- Ground-reference phase-term table (Hogan, Johnson, Kasevich), sizes for their 10 m-tower EP case: -k_eff g T^2 (-2.85e8 rad); k_eff R_e Omega_y^2 T^2; -k_eff T_zz v_z T^3; (7/12) k_eff g T_zz T^4; -3 k_eff v_z Omega_y^2 T^3; 2 k_eff v_x Omega_y T^2 (Coriolis); (7/4) k_eff g Omega_y^2 T^4; -(7/12) k_eff R_e T_zz Omega_y^2 T^4; recoil -(hbar k_eff^2/2m) T_zz T^3 — [Hogan, Johnson & Kasevich 2008, arXiv:0806.3261](https://ar5iv.labs.arxiv.org/html/0806.3261)
- Carraz 2014 closed-form for acceleration a = a_M + gamma (z - z_M): Phi ~ k_eff [ (z0 - a_M/gamma) gamma T^2 + (7/12) gamma^2 T^4 + v0 gamma T^3 ] (approximation of exact cosh/sinh form); non-closure dz ~ 4 v_rec gamma T^3 — [Carraz et al. 2014, arXiv:1406.0765](https://arxiv.org/pdf/1406.0765) (transcription of a partly garbled text layer)

Per-shot sensitivity, shot-noise limit, ASD
- Quantum projection noise: sigma_a = (1/(k_eff T^2)) (1/(C sqrt(N_det))) scaled by sqrt(t_c) for the ASD; GRICE parameter set: T = 0.5 s, C = 0.43, t_prep = 1 s, t_c = 2 s, N_det = 5e5, theta = 5e-11 K (50 pK), sigma_0 = 1e-4 m, sigma_a = 6e-10 m s^-2 tau^-1/2 (stated as 2.3 mrad per shot) — [Leveque et al. 2021, arXiv:2011.03382](https://arxiv.org/pdf/2011.03382)
- CARIOQA performance parameters (Table 2): 2T = 2 s, C ~ 0.8, t_prep = 1.5 s, t_c = 3.5 s, N_det = 1e5, effective temperature 100e-12 K, shot-noise sensitivity 3e-10 m s^-2 Hz^-1/2 (conservative) and 8e-11 m s^-2 Hz^-1/2 (enhanced, N up to 1e6); instrument shall explore < 1e-9 and target a QPN floor < 1e-10 m s^-2 Hz^-1/2; atom-chip BEC of 1e5 Rb atoms in 1 s and 38 pK 3D kinetic energy demonstrated — [Leveque et al. 2022 (CARIOQA)](https://arxiv.org/pdf/2211.01215)
- Encarnacao generalised phase noise: s_phi = 1/(C N^((1+alpha)/2)), alpha = degree of entanglement (alpha = 0 standard quantum limit 1/(C sqrt N); alpha = 1 Heisenberg limit 1/(C N)); shot-to-shot acceleration noise s_a = s_phi/(beta k_eff T^2); with T_cycle: s_a(ASD) = sqrt(T_cycle) s_a(shot); concurrent mode T_cycle = T_prep (interleaved), sequential mode T_cycle = 2T + T_prep, T_prep = 1 s assumed. Their "ambitious" CAI set (Table 2): lambda = 780 nm, C = 0.8, alpha = 0.25, beta = 2, T = 5 s, T_cycle = 1 s, cloud velocity 0 or 2.5 cm/s, attitude degradation factor 10 (atom number exponent illegible in PDF text layer) — [Encarnacao et al., arXiv:2404.07835](https://arxiv.org/abs/2404.07835)
- Literature contrast values used in models: 0.5 (Zahzam 2022), 0.6 (Zhu 2022), 0.65 (Peters 1999), 0.8 (Knabe 2022), max 1 (Douch 2018) — [Encarnacao et al.](https://arxiv.org/abs/2404.07835)
- CAI noise is modelled as flat (white) spectrum, in contrast to electrostatic accelerometers dominated at low frequency by thermal bias fluctuation and gold-wire damping with f^-n (n >= 1) behaviour — [Encarnacao et al.](https://arxiv.org/abs/2404.07835)
- Above f = 1/(2T) (but below 1/T_cycle when interleaving) the gradiometer sensitivity improves by a factor (2 T f)^(1/2) — [Carraz et al. 2014](https://arxiv.org/pdf/1406.0765)

Gradiometer (CAI-GG) differencing
- Two AIs separated by D, same Raman lasers: dPhi = Phi2 - Phi1 = k (a2 - a1) T^2 = k gamma D T^2 (single-diffraction form); common-mode noise (vibrations, laser phase) rejected; with double diffraction differential phase = 2 k D T_zz T^2 — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828)
- Per-shot gradient noise at QPN: sigma_Tzz = sqrt(2)/(2 sqrt(N) k D T^2) = 3.5 mE/shot for N = 1e6 detected atoms per interferometer, D = 0.5 m, T = 5 s; with ~1 s source production and interleaving (up to 8 interferometers simultaneously, effective cycle 1.2 s) this is low-mE/Hz^1/2; nominal white 5 mE/Hz^1/2 used in mission simulation — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828)
- Carraz concept: per measurement sigma_gamma = sigma_Phi * sqrt(2)/(k_eff T^2 d) (single-k form), sigma_Phi = 1/SNR ~ 1 mrad for N = 1e6; with double diffraction and T_cycle = 1 s: Delta_gamma = 3.5 mE/sqrt(Hz) and rotation-rate Delta_omega = 25 prad s^-1/sqrt(Hz) (from Coriolis with transverse launch velocity v_trans); 3-axis 4-pulse Ramsey–Borde variant (T1 = 2.5 s, T2 = 5 s): 4.7 mE/sqrt(Hz), 35 prad s^-1/sqrt(Hz), needs 4e6 atoms loaded; baseline d = 50 cm — [Carraz et al. 2014, Microgravity Sci. Technol. 26, 139](https://arxiv.org/pdf/1406.0765)
- Required cloud temperature vs T (coherence length = lambda_dB/2 must exceed non-closure dz): T = 1 s -> 6.5 uK (molasses); 2 s -> 100 nK (kinetic selection); 5 s -> 0.4 nK (BEC) — [Carraz et al. 2014](https://arxiv.org/pdf/1406.0765)
- Classical baseline for comparison: GOCE gradiometer 10–20 mE/Hz^1/2 in the 5–100 mHz MBW, with noise PSD rising as 1/f below — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828); an EA gradiometer from MicroSTAR accelerometers (2e-12 m/s^2 floor) with L_GG = 0.5 m gives ~4 mE floor; time-variable gravity needs sub-mE gradiometry (~one order better than MicroSTAR) — [Encarnacao et al.](https://arxiv.org/abs/2404.07835)
- QSG4EMT gradiometer assumption: quantum gradiometer noise floor ~4 uE; ~40 uE (or better) needed to sense time-variable gravity (search-result summary of Zingerle et al. 2024; full text not retrieved) — [Zingerle et al. 2024, Earth Planets Space 76:101 (DOAJ record)](https://doaj.org/article/eca7c3c5bd254f5696e933d48d968dc8)
- Laser-linked "distributed gradiometer" (GRICE): along-track gradient from two CAI accelerometers on two satellites plus laser ranging L: d a_x/d x = (1/L)(S1 - S2 + d^2L/dt^2); combined instrument limited by atom accelerometers 1e-5–1e-2 Hz and by ranging noise 1e-2–1 Hz; ranging requirement 40 nm/Hz^1/2, reference-laser stability 1e-13 Hz^-1/2 — [Leveque et al. 2021](https://arxiv.org/pdf/2011.03382)

Contrast loss (rotation, gradients, temperature)
- Without rotation compensation (Omega_m = 0) the Sagnac term 4 k v_x Omega_y T^2 dephases the cloud; negligible contrast loss requires sigma_v << 1/(4 k Omega_y T^2), i.e. temperature Theta << T0 = m_Rb/(16 k_B k^2 Omega_y^2 T^4); for nadir Omega_y = 1.2 mrad/s, T0 = 3 fK (unachievable) -> rotation compensation mandatory; gradient condition Theta < T1 = m_Rb/(4 k_B k^2 T_zz^2 T^6) ~ 100 pK; inertial pointing tolerates up to Omega_0 = 6 urad/s at 100 pK (same bound applies to residual mismatch Omega_m - Omega_y) — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828)
- Simplified rotation contrast model: C = C0 exp(-2 k_eff^2 T^4 [sigma_y^2 dOmega_z^2 + sigma_x^2 Omega_z^4 + 4 sigma_vy^2 Omega_z^2]) (sigma_x, sigma_y cloud size, sigma_vy velocity spread, dOmega_z angular acceleration) — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- Double-diffraction rotation contrast: C proportional to exp(-(k_eff sigma_r(2T) T)^2 (Omega_x^2 + Omega_y^2)), wave-packet size sigma_r(t) = sqrt((hbar/sigma_p)^2 + (sigma_p t/M)^2), sigma_p = sqrt(2 k_B M theta) — [Leveque et al. 2021](https://arxiv.org/pdf/2011.03382)
- Monte-Carlo double-diffraction design point: effective Rabi frequency 40e3 rad/s, 100 pK -> C ~ 80% and ~80% detected-atom fraction (parallel beams); tilted mirrors with 1 cm waist -> C ~ 92%, 95% detected; waist > 8 mm needed for < 1 mrad curvature phase error; initial vertical-velocity control better than 20 um/s (0.05 mrad per um/s); mirror local peak-to-valley <= lambda/1000 — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828)

Microgravity advantage
- Sensitivity scales as T^2; on ground, T is limited by the atoms' fall; ground absolute gravimeters reach low nano-g accuracy and gradiometers ~nano-g/m differential sensitivity; in space superposition can be kept for seconds -> "several orders of magnitude" better long-wavelength sensitivity expected — [Leveque et al. 2022 (CARIOQA)](https://arxiv.org/pdf/2211.01215)
- State-of-the-art comparison (Table 1): SYRTE lab absolute gravimeter 5e-8; commercial (iXblue/Muquans) 5e-7; ICE/LP2N microgravity (parabolic flights) 6e-7; CARIOQA pathfinder target 1e-10; future Quantum Space Gravimetry missions 1e-12 m s^-2 Hz^-1/2 — [Leveque et al. 2022](https://arxiv.org/pdf/2211.01215)
- Space requires ultra-cold sources (< 100 pK) to keep contrast and SNR at long T, at the cost of low atom flux — [Leveque et al. 2022](https://arxiv.org/pdf/2211.01215)

### Inferences
- Consistency checks a simulator can use as unit tests (my arithmetic on cited parameters): CARIOQA (T = 1 s, C = 0.8, N = 1e5, t_c = 3.5 s, dPhi = 2 k_eff a T^2, k_eff = 1.61e7) gives sigma_phi = 1/(0.8*316) = 3.95 mrad, per-shot 1.23e-10 m/s^2, ASD 2.3e-10 m s^-2 Hz^-1/2 (paper: 3e-10 conservative); with N = 1e6, 7.3e-11 (paper: 8e-11). GRICE (T = 0.5 s, C = 0.43, N = 5e5, t_c = 2 s) gives 5.8e-10 (paper: 6e-10); the paper's "2.3 mrad per shot" matches 3.3 mrad/sqrt(2), so treat that number as inconsistent. Trimeche: sqrt(2)/(2*1e3*1.61e7*0.5*25) = 3.5e-12 s^-2 = 3.5 mE/shot (matches).
- Low-frequency closed form of the acceleration transfer function implied by Cheinet's G(omega): |H_a(omega)| = k_eff |H(omega)|/omega^2 = (4 k_eff/omega^2) sin^2(omega T/2), which tends to k_eff T^2 as omega -> 0 (multiply by 2 for double diffraction). A simulator can generate CAI output by convolving the true acceleration time series with the triangular f_a(t) and sampling once per T_c, then adding white QPN; aliasing of spectral content above 1/(2 T_c) must be modelled (Dick-type effect).
- Recommended default simulator noise model for a space CAI accelerometer: S_a^(1/2)(f) = sigma_shot sqrt(T_c) (white) for f < 1/(2T), plus coloured terms from rotation-rate knowledge (Coriolis 2 Omega x v, centrifugal Omega^2 x), wavefront/temperature systematics, and dead-time aliasing; the white floor values found range from 6e-10 (near-term) through 1e-10 (CARIOQA target) to 1e-11 / 1e-12 (future missions).
- Frequency-to-degree mapping used in the papers is f ~ n * f_orb (f_orb ~ 0.18 mHz at ~90 min period): Encarnacao's "30 mHz or SH degree 170" and "10 mHz (SH degree 57)" are consistent with this.

## 2. Hybrid (CAI + electrostatic) accelerometers, their noise models, rotation compensation (tip-tilt mirror), and BECs in space (MAIUS, CAL, BECCAL, China Space Station)

### Takeaway
Hybridisation uses the electrostatic accelerometer (EA) to resolve the CAI fringe ambiguity and fill CAI dead time, and the CAI to estimate the EA's low-frequency bias/drift (and scale factor), via either a simple recursive bias loop (Zahzam 2022), an extended Kalman filter (HosseiniArani 2024), or fringe-lock algorithms (Kaczmarczuk 2025); simulated gains are large if temporal aliasing is ignored (1–2 orders of magnitude in degree RMS) but largely vanish once aliasing is included unless the constellation is multi-pair. Rotation is handled by counter-rotating (piezo tip-tilt) Raman mirrors or by using the EA proof mass itself as the Raman mirror; BEC/atom-interferometry in space has been demonstrated on sounding rockets (MAIUS-1), on the ISS (CAL) and on the China Space Station (CSSAI, gyroscope and accelerometer with T = 75 ms), while BECCAL has slipped to a 2027 launch.

### Cited Findings

Electrostatic accelerometer reference noise levels (for the "classical" branch of a simulator)
- EA specs table (Zahzam 2022, Table 1): CHAMP noise floor 2e-9 (USA and LSA); GOCE 2e-12 (USA) / 2e-10 (LSA); GRACE-FO 1e-10 (USA) / 1e-9 (LSA); NGGM 3e-12 (both) m s^-2 Hz^-1/2. Proof-mass 72 g (CHAMP), 320 g (GOCE), 72 g (GRACE-FO), 507 g (NGGM); USA ranges +/-1e-4, +/-6e-6, +/-7e-5, +/-1e-5 m/s^2; total mass/power ~10–15 kg, 2–15 W. EAs have ~1 Hz bandwidth, 1e6 dynamic range, continuous output, but thermally driven bias instability — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- NGGM "goal" accelerometer ASD: s(f) = 5e-12 sqrt(1 + (0.001/f)^2 + (100 f^2)^2) m s^-2 Hz^-1/2 (Massotti et al. 2021); MicroSTAR ASD (Christophe et al. 2018): s(f) = 2e-12 sqrt(1.2 + 0.002 f^-1 + 6000 f^4) m s^-2 Hz^-1/2 (last exponent read from a garbled glyph; 4 is my reading) — [Encarnacao et al.](https://arxiv.org/abs/2404.07835)
- GRACE-FO LRI range-noise ASD (Kornfeld et al. 2019) as used by Encarnacao: s_LRI(f) = 8e-8 sqrt(1 + (f/0.003)^-2) sqrt(1 + (f/0.01)^-2) m/Hz^1/2 (coefficient exponent read from garbled glyph); NGGM goal ranging scales with inter-satellite distance L_ISR; predicted future ranging ASDs of form L_ISR (a/f + b/f^2) for 2030, 2033 (factor 2 better) and 2040 (one order better, LISA-like) — [Encarnacao et al.](https://arxiv.org/abs/2404.07835)
- MicroSTAR (ONERA, cubic proof mass) for NGGM: instrument phase C started early 2026; mechanical sensor TRL 6, electronics TRL 5; target a few 1e-12 m s^-2/sqrt(Hz) — [GSTM2026 session A.3, abstract GSTM2026-35](https://meetingorganizer.copernicus.org/GSTM2026/session/59410)
- In HosseiniArani 2024: GRACE-like E-ACC ~1e-10 m/s^2/sqrt(Hz) above 1e-3 Hz with large noise below; improved E-ACC ~1e-11; Q-ACC state of the art ~5e-10 (Section 2.2; Section 1.2 cites ~1e-10 — internally inconsistent), near future ~1e-11 — [HosseiniArani et al. 2024](https://arxiv.org/html/2405.11259v1)

Hybridisation algorithms
- Zahzam 2022 scheme: inputs a_EA at 1 kHz and CAI P_i at 1/T_c (0.25 Hz for T_c = 4 s, 2T = 2 s); EA convolved with the CAI response function and de-biased to predict the fringe; bias recursion b_{i+1} = b_i + G_b (a_EA,i^hyb - a_CAI,i) (G_b sets hybridisation time constant); dead-time filling a_Hyb,i = a_CAI,i + [a_EA * (f_a,Tc - f_a,T)/T^2](../../../../research_notes/Satellite%20gravimetry%20data%20and%20Rust%20tooling/t_i); main output used in gravity simulations is the continuous de-biased EA (a_EA - b_i) — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- Zahzam simulation noise scenarios (Table 2): CAI white floor case 1 = 4e-8, case 2 = 1e-9, case 3 = 1e-10, case 4 = 1e-11 m s^-2 Hz^-1/2; EA low-frequency slopes 1/f, 1/f^2, 1/f^3 with corner frequencies 0.3, 1, 3 mHz; hybrid ASD = min-envelope (CAI below the corner, EA above) — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- Scale-factor analysis: relative scale-factor knowledge 2e-3 (EA) vs 1e-5 (hybrid); for drag-free (NGGM-like) flight the scale-factor error is masked by noise in both cases; without drag compensation (361 km drag model) the EA retrieval error is dominated by scale-factor error from 0.2 to 10 mHz, which a case-2 1D (along-track) hybrid removes; a constant bias only affects C00 and is absorbed — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- Lab demonstrations (ONERA): EA proof mass used as the CAI Raman mirror; ground hybrid with T = 20 ms; CAI contrast typically C = 0.39, sensitivity 8e-7 m s^-2/Hz^1/2; rotation excitation at 5.435 Hz (1/(4T), T = 46 ms) drops contrast by ~93% uncompensated, active proof-mass counter-rotation recovers ~85% contrast at optimum gain; simulated in-orbit case: 1.1 mrad/s orbital rate, T = 1 s, contrast fully lost with a fixed mirror and recovered by rotating the proof mass — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- HosseiniArani 2024: Extended Kalman filter; observation h_i = A cos(dPhi_i + phi_L,i) + nu with A = 0.5, nu = 0.5, laser phase steered to mid-fringe (dPhi + phi_L = pi/2); bias estimate B_i = -K_i (p_CAI,i - h_i(dPhi_i)); K_i = P_i^- H_i/(R_i + H_i^2 P_i^-); H_i = dh/dB = 2 k_eff T^2; P_i^- = P_{i-1}^+ + Q_i; P_i^+ = (1 - K_i H_i)^2 P_i^- + K_i^2 R_i. E-ACC sampled at 10 Hz. Q-ACC parameter sets (state of the art / near future): atoms 5e5 / 1e6; temperature 40 pK / 10 pK; laser waist 10 / 20 mm; cloud position error 3e-5 m; transverse velocity 33e-6 / 20e-6 m/s; rotation-rate measurement error 2.2e-7 / 6.6e-8 rad/s; 2T = 5 s / 10 s — [HosseiniArani et al. 2024](https://arxiv.org/html/2405.11259v1)
- Kaczmarczuk et al. 2025 compare two hybridisation algorithms: Algo I (direct phase extraction; ambiguity resolved by nearest classical estimate; bias and scale-factor recursions b_{i+1} = b_i + G_b (a_q,i - a_c,i), eta_{i+1} = eta_i + G_eta (a_q,i - a_c,i)/a_CA,i, regularised) and Algo II (fringe-lock using three consecutive joint measurements, adapted from Merlet 2009); model a_QA = eta a_CA + b, phase Phi = k_eff a T^2 - alpha T^2 (chirp); Algo II more robust to errors in C and P0, Algo I slightly better without errors; tested with 2T = 40 ms, T_c = 0.1 s synthetic data and GIRAFE airborne data over Greenland — [Kaczmarczuk et al. 2025, arXiv:2510.11201](https://arxiv.org/html/2510.11201v1)
- Machine-learning "accelerometer transplant" (MLP/LSTM/BiLSTM) comparing electrostatic, cold-atom and hybrid accelerometers was presented at GSTM 2026 (Romeshkani et al.) — [GSTM2026 session A.3](https://meetingorganizer.copernicus.org/GSTM2026/session/59410)

Rotation compensation and attitude requirements
- Trimeche design: two mirrors for the pi/2 pulses on piezoelectric tip-tilt mounts; relative angle between consecutive reference mirrors ~7 mrad (mean satellite rotation over T); power budget of actuators not negligible; alternative with a single rotating mirror. Three-axis gradiometry can measure the residual pitch-rate mismatch to Delta(dOmega_y) = 0.9 nrad/s for sigma_T = 3.5 mE, Omega_orb = 1.17 mrad/s; inertial-frame mixing error ~ dtheta x T reaches 3 mE for dtheta = 1 urad — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828)
- CARIOQA platform requirements: cloud at satellite centre of mass within 1 mm, monitored to +/-0.1 mm; residual cloud velocity < +/-0.01 mm/s; integrated dynamic disturbances < 1e-10 m/s^2 -> reaction wheels excluded, electric thrusters used (8 thrusters, max 350 uN, Isp > 3000 s); pointing error < 0.5 deg per axis; angular-rate error < 5e-6 rad/s (orbital axis) and < 5e-5 rad/s (others); rate knowledge < 5e-6 rad/s; gyro-stellar estimation with star tracker (12/96 urad 1-sigma) and gyro (ARW 0.005 deg/sqrt(h)); simulated angular error 2e-6 rad/s std (8e-6 max) — [Leveque et al. 2022](https://arxiv.org/pdf/2211.01215)
- Encarnacao: concurrent mode (cloud launched transversely at ~2.5 cm/s) is dominated by Coriolis 2 omega x v_cloud errors, ~2 orders above the CAI sensitivity and insensitive to attitude compensation; sequential mode (cloud prepared at CoM, zero initial velocity) is a factor ~3 worse in white noise (longer cycle) but Coriolis error ~2 orders below; quantum accelerometry needs LISA-level differential wavefront sensing if no drag-free control, GRACE-FO DWS suffices with 3D drag-free — [Encarnacao et al.](https://arxiv.org/abs/2404.07835)
- NASA cross-track QGG rationale: in a near-polar orbit the cross-track axis needs no active rotation compensation with imaging readout (radial/along-track would); angular misalignment couples in-line gradients only at second order, off-diagonal gradients at first order but these are ~3 orders smaller in cross-track; GRACE-FO star camera 10 urad accuracy cited; self-gravity of a 600 kg GRACE-FO-like spacecraft ~60 E cross-track at centre, >1e5 times a 200 uE noise floor — static but its time variation must be controlled — [NASA Mass Change Hybrid SST-QGG Technology Report (2023)](https://science.nasa.gov/wp-content/uploads/2023/05/2MCHybridSST_QGGTechnologyReport.pdf)

### Inferences
- For a simulator, a hybrid can be represented as: a_hyb(f) ASD ~ min-envelope of CAI white floor (below a crossover ~0.3–3 mHz) and EA ASD (above), but realistic implementations require explicit fringe-ambiguity resolution and the EA-to-CAI response-function convolution; the HosseiniArani EKF equations above are directly implementable (state = EA bias, measurement = CAI transition probability).
- Since CSSAI's T is 75 ms and CAL's interferometers are ~100 ms class, no orbital instrument has yet demonstrated the T ~ 1–5 s regimes assumed in all mission studies; that remains the main gap the pathfinders (CARIOQA, QGGPf) target.

## 3. Missions and studies: status, timelines, consortia, expected sensitivities (as of October 2026)

### Takeaway
Two quantum gravimetry pathfinders are funded and targeting ~2030: Europe's CARIOQA (single-axis BEC accelerometer on a dedicated CNES/DLR-led satellite; Phase B since Oct 2025, TRL-6 goal; launch "2030"/"early 2030s") and NASA JPL's QGGPf (single-axis cross-track BEC gradiometer, < 100 mE/sqrt(Hz) from 0.1 mHz–0.1 Hz; Infleqtion $20M follow-on on 27 Aug 2026, NASA total $40M, LEO launch 2030). Classical successors fly first (GRACE-C Dec 2028; NGGM 2032, together MAGIC), and quantum is positioned as a post-MAGIC hybrid then full-quantum mission; ESA's QSG4EMT study and the new EU–Japan FEATS-G simulation project (start 2026) define future multi-pair quantum constellations.

## 4. Mission performance simulation methodology (closed loop, variance–covariance, ASD -> SH coefficient errors, degree-error curves, software)

### Takeaway
Published quantum-gravimetry performance assessments mostly use full closed-loop (time-domain) simulations: generate noise-free orbits/observables from a reference field (EIGEN-6C4, EGM2008, ESA ESM/AOHIS for time-variable signal), add coloured instrument noise synthesised from ASDs (plus attitude, orbit, ranging and de-aliasing model errors), solve SH coefficients by least squares (or SVD), and compare with truth via degree RMS / degree medians in geoid height or EWH; reduced-scale or analytical/variance-covariance shortcuts are validated against full-scale tools. Named tools are in-house: IAPG/TUM full- and reduced-scale tools, ZARM/DLR XHPS, LUH/IfE LS on the LUIS cluster, CNES/GRGS SVD inversion, PoliMI LS with Monte Carlo covariance; GROOPS was not named in any retrieved quantum paper.

### Cited Findings
- Trimeche 2019 closed-loop simulator (LUH/IfE): inputs gravity model + noise-free orbit, angular velocity and attitude, and sensor noise spectra; outputs noisy orbit, angular velocity, attitude, gradients; gravity potential V(r, theta, lambda) = (GM/R) sum_{n=0}^{N} (R/r)^(n+1) sum_{m=0}^{n} (C_nm cos m lambda + S_nm sin m lambda) P_nm(cos theta); observation equation V_ij = R (d^2 V/dx_i dx_j) R^T (rotation between gradiometer and Earth-fixed frames); large LS adjustment on LUIS clusters. Data: 71 days of real GOCE orbit (2 Mar–10 May 2013), mean altitude 239 km, interpolated to 1 Hz; noise-free gradients from EIGEN-6C4 to d/o 360; orbit noise 2.6 cm; angular rate from 3 star trackers + gyro combined by Wiener filter (Stummer et al. model); gradiometer white 5 mE/Hz^1/2; recovery to d/o 240 (58,077 unknowns); true and formal errors; degree medians in geoid height; extrapolation from 71 d to 8 months by sqrt(t); result: 8-month 3-axis nadir CAI-GG at 239 km beats full GOCE SGG (47 months), ~2-fold for degrees > 50; V_zz-only solution ~2x better than V_xx or V_yy; V_xx sensitive to (near-)zonal, V_yy to sectorial coefficients; polar gaps degrade zonals — [Trimeche et al. 2019](https://arxiv.org/pdf/1903.09828)
- HosseiniArani 2024: closed loop; orbits from XHPS (ZARM/DLR, MATLAB/Simulink); force models EGM2008, drag, SRP, albedo, Earth IR; GRACE geometry; circular polar 480 km (also 300 km); gravity recovery after Wu (2016); reference EIGEN-6C4; maps to d/o 90, spectra to d/o 180; hybrid improves degree RMS geoid by ~1 (state of the art) to ~2 (near future) orders of magnitude and reduces striping; at 300 km, initial wobbling causes bias excursions, avoided by delayed filter start — [HosseiniArani et al. 2024](https://arxiv.org/html/2405.11259v1)
- Zahzam/Abrykosov (IAPG TUM): reduced-scale simulations validated against IAPG's full-scale tool; GRACE-type (near-polar pair) and Bender-type (+ inclined pair); 450–500 km, 200 km separation, 30-day retrieval; only accelerometer and LRI noise in first group; hybrid improves degree RMS up to factor 3 below n = 10 (GRACE-type, static field only); with corner 1 mHz gain limited to n < 20; once temporal aliasing is included the benefit is largely lost (Bender keeps gain to n ~ 5) — "improved de-aliasing models or specific constellations" needed; ASD plots overlay "maximal contributing observation frequency" per SH degree — [Zahzam et al. 2022](https://arxiv.org/pdf/2206.00634)
- Leveque 2021 (GRICE, CNES/GRGS): "true" data from unperturbed gravity models + non-gravitational forces (drag, solar, Earth visible and IR radiation) + propagated orbits; model noise as fractions of present-day model differences (atmosphere, ocean response, ocean tides); instrument noise white: range 2e-8 m (1-sigma, 5 s sampling, derivatives by sliding 100 s polynomial), acceleration 3e-10 m/s^2 (no calibration parameters, no drift); a-priori ephemeris noise ~cm; static field CNES-GRGS-RL03.v2 / ITSG-Grace2014; unknowns d/o 2–90; SVD inversion truncating smallest singular values (reduces noise up to one order for degrees 50–90 vs range-rate); comparison with ITSG-Grace2018 formal errors: GRACE ~1 mm EWH at degree 3 to 30–40 cm EWH at degree 90 (2 cm at degree 45) vs GRICE 7–8 cm EWH at degree 90 (~5x better short wavelengths); low degrees (< 20) poorly determined by acceleration approach — [Leveque et al. 2021](https://arxiv.org/pdf/2011.03382)
- QSG4EMT (Kusche et al. 2025): closed loop with two retrieval chains — TUM linear-acceleration approach (weekly SH solutions) and PoliMI least squares with Monte-Carlo-rescaled covariance plus collocation; 4-week orbits split into 7-day arcs, 10 s sampling; 12-year ESA ESM period; target signal HIS-upd (AOHIS with updated solid Earth incl. 9 earthquakes); AOD errors per Shihora et al. 2024 (AOe07 set, conservative); ocean-tide error EOT11a vs GOT4.7; products to d/o 120 (multipair), applications at d/o 90 with DDK5 filter — [Kusche et al. 2025, GJI](https://academic.oup.com/gji/article/242/2/ggaf195/8151505)
- Encarnacao et al.: analytical error propagation in the spectral domain — compare attitude-error, Coriolis/centrifugal, ranging and CAI noise ASDs against the time-variable gravity signal ASD; frequency range of interest 0.2 mHz (orbital) to ~20 mHz (SH degree ~120 class); with 2040 LRI and the ambitious CAI, temporal signal resolved up to 30 mHz (SH degree 170) and SNR ~10 at 10 mHz (degree 57); centrifugal-term reconstruction errors dominate — [Encarnacao et al.](https://arxiv.org/abs/2404.07835)
- New community resources (GSTM, Oct 2026): ESA Earth System Model 3.0 (Jan 2007–Dec 2020, 6-hourly, adds earthquakes, updated GIA, Arctic glaciers, ice dynamics, AMOC bottom pressure, synthetic error series); ESA-SING simulated L2/L3 products (12 years, 30-day and 5-day, GRACE-C-like, NGGM, MAGIC); other studies use closed-loop GRACE-C/NGGM/MAGIC simulations over 200+ basins and 50-year end-to-end runs — [GSTM2026 session A.3](https://meetingorganizer.copernicus.org/GSTM2026/session/59410)
- NASA hybrid SST+QGG simulations compared GRACE requirements, GRACE-FO performance, radial QGG at 450 km and 250 km, and hybrid at ~500 km, as degree-error curves; QGG adds sectorial (n = m) information, SST near-zonal, GPS lowest degrees; aliasing errors concentrate in near-sectorials, so cross-track QGG mitigates aliasing — [NASA Hybrid SST-QGG report](https://science.nasa.gov/wp-content/uploads/2023/05/2MCHybridSST_QGGTechnologyReport.pdf)

### Inferences
- Standard metrics a simulator should output (textbook definitions, not verified against a fetched source in this session): degree RMS of coefficient errors sigma_n = sqrt( sum_{m=0}^{n} (dC_nm^2 + dS_nm^2) ); geoid degree error N_n = R sigma_n and cumulative geoid error sqrt(sum_{k<=n} N_k^2); EWH degree error (Wahr et al. 1998, J. Geophys. Res. 103(B12)): EWH_n = (R rho_e/(3 rho_w)) ((2n+1)/(1+k_n)) sigma_n, with rho_e ~ 5517 kg/m^3, rho_w = 1000 kg/m^3, k_n load Love numbers; degree medians (Trimeche) are more robust than RMS to polar-gap-degraded zonals.
- A fast variance–covariance (semi-analytic) path consistent with the papers: build normal equations N = A^T W A for the observation type (gradients V_ij, range accelerations, accelerations), with W the inverse of the noise covariance built from the instrument ASD (or apply a whitening/decorrelation filter in time domain, as done for GOCE's 1/f noise), then sigma(C_nm) = sqrt(diag(N^-1)); for white CAI noise W is diagonal, which is a computational advantage over EA-based missions. Validate against a closed-loop run as IAPG did.
- Rough ASD-to-degree heuristic: observation frequency f ~ n f_orb; an ASD increase at low f (EA 1/f^k below 1–5 mHz) maps to errors in degrees below ~6–30, which is where CAI's flat spectrum helps; ranging noise rising at high f maps to high degrees.

### Gaps
- No retrieved quantum-gravimetry paper explicitly names GROOPS; whether QSG4EMT/FEATS-G use GROOPS or in-house TUM/PoliMI/GFZ code is not confirmed (FEATS-G mentions VENQS for sensor simulation; its expansion was not given).
- Exact closed-form analytical "ASD -> SH error" formulas (e.g., Sneeuw-type lumped-coefficient/semi-analytical approach) used in recent quantum papers were not retrieved.
